Use this as a lookup list. Read only the section relevant to the step you are implementing.

## Official documentation — recommended order
1. [Python tutorial](https://docs.python.org/3/tutorial/) — syntax and functions.
2. [Python classes](https://docs.python.org/3/tutorial/classes.html) — understand MazeEnv.
3. [Virtual environments](https://docs.python.org/3/library/venv.html) — isolate packages.
4. [NumPy quickstart](https://numpy.org/doc/stable/user/quickstart.html) — arrays and shapes.
5. [Gymnasium environment creation](https://gymnasium.farama.org/tutorials/gymnasium_basics/environment_creation/) — reset and step.
6. [Gymnasium Env API](https://gymnasium.farama.org/api/env/) — return values and episode endings.
7. [Stable-Baselines3 installation](https://stable-baselines3.readthedocs.io/en/master/guide/install.html) — supported setup.
8. [Stable-Baselines3 PPO](https://stable-baselines3.readthedocs.io/en/master/modules/ppo.html) — model parameters.
9. [SB3 custom environments](https://stable-baselines3.readthedocs.io/en/master/guide/custom_env.html) — compatibility checks.
10. [Matplotlib quick start](https://matplotlib.org/stable/users/explain/quick_start.html) — plots.

## Suggested learning loop
1. Read the relevant official documentation.
2. Read the corresponding MazeMind source file.
3. Run the smallest example.
4. Change one value and predict what happens.
5. Run it and compare the result with your prediction.
6. Write one sentence explaining the concept in your own words.

## Scope reminder
Do not add a web app, database, cloud deployment, or second algorithm until the environment, training, and evaluation work and you can explain them.
